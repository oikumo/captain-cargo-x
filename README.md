# Captain Cargo X

3D arcade air/sea combat shoot-'em-up — browser port (TypeScript · three.js ·
Vite), low-poly retro look.

```sh
npm install
npm run dev        # fly
npm run harness    # repo process check (typecheck, tests, budgets, boundaries)
npm test           # vitest only
```

Documentation: `doc/GDD.md` (design) · `spec/README.md` (contracts) ·
`doc/omt-ts-methodology.md` (method) · `spec/meta-harness.md` (process).
`WORK.md` is the task ledger.
